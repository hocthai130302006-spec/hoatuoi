BLOOMISTRY WEBSITE
==================
Các file:
- index.html       Trang chủ
- dichvu.html      Danh sách gói + giá
- gioithieu.html   Về chúng tôi
- dathang.html     Form đặt hàng
- style.css        CSS dùng chung
- script.js        JavaScript dùng chung
- assets/          Logo + ảnh sản phẩm/ảnh nền

Cách dùng:
1. Giữ nguyên cấu trúc thư mục.
2. Mở index.html bằng trình duyệt.
3. Có thể đổi SĐT, Zalo, Facebook và địa chỉ trực tiếp trong phần footer.
4. Form hiện là giao diện demo phía trình duyệt; muốn nhận đơn thật cần kết nối backend/Google Forms/Formspree hoặc hệ thống quản lý đơn hàng.
